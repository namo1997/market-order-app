# โต๊ะเทียบเอกสาร — แนวทาง Local 9 ตุลาคม 2569

ต่อจาก `DESK_VIEW_HANDOFF.md` ด้วย tasteful-ui โหมด production_ui_implementation ตามม็อกอัปและแนว Liquid Glass ที่เลือกไว้แล้ว
เป็นการแก้ในแอปเดิม ไม่ใช่พรีวิวหน้าจอแยก ไม่เปลี่ยน API หรือกฎการเงิน

- หนึ่งงานต่อจอ: รูปหลักฐานเต็มกรอบไม่ถูกตัด กระดาษขาว; ยอด/เลขอ้างอิงที่ OCR พบมีเส้นเชื่อมและ ✓/✕
- กระจกเฉพาะปุ่ม แท่น และแผ่นลอย เนื้อหาอ่านง่าย; IBM Plex Sans Thai และไอคอนเส้นชุดเดิม
- บิลไม่มีคู่ถามวิธีจ่าย สลิปไม่มีคู่ถามหาบิล รูปอื่นถามประเภท; ปุ่มรองอยู่ ⋯ และมี tooltip
- คู่ติดธงยอดแสดงสองค่าที่เลือกได้กับกรอกเอง ยอดว่างแสดง “ยังไม่ทราบยอด” และใช้ฟอร์มเดิม
- แชทอยู่ซ้าย ใช้ focus เดิมและฟองแอบดู 5 วินาที ไม่สร้างคำตอบจาก AI
- ย้าย node เดิมเข้าแผ่นตัวเลือกแล้วคืนกลับ รักษา input/handler/เงื่อนไขยืนยัน ไม่ทำสำเนาฟอร์มเพื่อส่ง API เอง
- Classic ยังเป็นค่าเริ่มต้น; โต๊ะทำงานตั้งแต่ 1100px ขึ้นไป เคารพ reduced motion/transparency
- กลุ่มหลายเอกสาร สำรองจ่าย รอบจ่าย และงานซับซ้อนยังมีทางไปมุมมองรายการตาม handoff

ตรวจบนสำเนา SSD ที่ 1120/1280/1440/1920px ทั้งสว่างและมืด พร้อมเส้นหลัง resize, ขาดกล่อง, event เก่า,
คิวชุดง่าย, เมนู/ฟอร์มเดิม, peek, หมดคิว และเทียบ classic กับ HEAD ของงานนี้

การทดสอบปุ่มเขียนข้อมูลรอบนี้ตรวจการเปิด dialog/guard และการส่งต่อไป handler เดิมโดย spy ในเบราว์เซอร์
ไม่มีการยืนยันจ่ายเงิน จัดประเภท บันทึกยอด ส่ง LINE หรือเรียก AI จริงจาก browser checks
Backend check/smoke แยกเป็น regression บน mock fixtures ผ่าน SSD runner
