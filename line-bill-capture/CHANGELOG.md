## 2. หน้าตาใหม่ (v4 — Soft Dashboard)

แรงบันดาลใจจากงาน dashboard แนวพาสเทล การ์ดมุมมน ตัวเลขใหญ่คู่ป้ายสถานะ

### ระบบพื้นฐาน
- ยุบ `<style>` **5 ก้อนที่ทับกัน** เหลือชีตเดียว (AGENTS.md เตือนเองว่าการซ้อนชั้นเป็นปัญหา)
- เลิกฉีด CSS จาก JS (`flagCss`, `actionBarCss`) ที่เคยทับสไตล์หลักตอน runtime
- ฟอนต์ **Anuphan** · โทนพาสเทล mint / lemon / rose / sky / lilac ใช้เป็น **สีสถานะเท่านั้น** ไม่ใช้ตกแต่ง
- ย้ายแท็บบนหัวเป็น **แถบข้างที่ย่อ/ขยายได้** — จำสถานะใน localStorage, กด `[` สลับ, ตอนหุบมี tooltip

### แชท
- **ลากปรับความกว้างได้** 250–760px · ดับเบิลคลิกหรือ `Home` รีเซ็ต · ลูกศรซ้าย/ขวาปรับทีละ 12px (`Shift` = 40px)
- **หุบแถบข้าง → แชทกว้างขึ้น 162px พอดี** กับพื้นที่ที่ได้คืน เก็บ "ความกว้างฐาน" แยกจากโบนัส
  จึงสลับหุบ/กางกี่รอบก็ไม่ drift
- ปุ่ม `ดูสลิป` / `→ ไปยังถัง` ย้ายจากใต้รูปมาอยู่**ข้างขวาของรูป** · รูปใหญ่ขึ้น 210px → 340px
- **ปุ่ม `→ ไปยังถัง` เปลี่ยนสีตามสถานะ** ใช้ชุดสีเดียวกับแท็บถังงาน เพื่อให้สีหมายถึงสิ่งเดียวกันทั้งระบบ

## 3. ปรับโฟลว์การทำงาน

จากการไล่ดูจุดที่กดได้ทั้ง 46 จุดในหน้า admin แล้วหาว่าตรงไหนทำให้ผู้ใช้งง/ติดกับดัก

### อุดทางตัน
- ถัง **อื่น ๆ** เพิ่ม `นี่คือบิล` / `นี่คือสลิป` — เดิมถ้า AI จัดผิดมากองนี้ **กู้คืนจากหน้าจอไม่ได้เลย**
- ถัง **เสร็จแล้ว** เพิ่ม `ยกเลิกการยืนยัน` — เดิมยืนยันผิดแล้วแก้ไม่ได้
- ทุกถังมี `ข้ามไว้ก่อน` — เดิมถ้าตัดสินใจไม่ได้ต้องเลื่อนกลับไปคลิกในคิวเอง

### ลดของรก / ลดการกดพลาด
- ยุบปุ่ม `วิเคราะห์` + `จัดคู่ใหม่` เป็นเมนู **เครื่องมือ AI** ที่บอกขอบเขตในตัวเลือก
  (เดิม `จัดคู่ใหม่` ยิงทั้งฐานข้อมูลโดยไม่มี confirm และลอยอยู่บนหัวตลอด)
- ซ่อนช่องวันที่ 2 ช่องบนหัว (JS ยังใช้ค่าอยู่ แต่ผู้ใช้แตะไม่ได้แล้ว)

### ตัวเลขและความคืบหน้า
- **ป้าย AI นับความคืบหน้าสด** `AI อ่านแล้ว 39/50` พร้อมแถบ ถามซ้ำทุก 3 วิระหว่างมีคิว แล้วหยุดเอง
  อ่านครบแล้ว toast แจ้ง + รีเฟรชหน้าให้อัตโนมัติ
- **AI ปิดอยู่ → แสดง `AI ปิด · คิว N` และไม่ poll** ไม่แกล้งบอกว่ากำลังทำงานทั้งที่ไม่มีอะไรเดิน
- **รูปที่อ่านไม่สำเร็จแสดงเป็นป้ายแดง** + เมนู `ลองอ่านรูปที่ล้มเหลว` สั่งกลับเข้าคิวได้

### หน้าต้องตรวจยอด
- เปลี่ยนจาก 3 ปุ่มที่ลงท้ายว่า "เคลียร์ธง" เหมือนกันหมด เป็น **เลือกยอดที่ถูก**
  (`ยอดในเอกสารถูก` / `ยอดที่แจ้งในแชทถูก` / `พิมพ์ยอดอื่น`) — คำถามจริงมีข้อเดียวคือยอดไหนถูก

## 4. บั๊กที่เจอและแก้แล้ว

ตรวจ 3 ชั้น: ความสอดคล้องของข้อมูล 11 แบบ · เทียบสูตรนับงานสองฝั่งทั้ง 64 รอบ · สภาพปฏิบัติการ

### 4.1 งานผี — บอร์ดนับ แต่เปิดเข้าไปไม่เจอ

เดิม **8 จาก 64 รอบ (12.5%)** ตัวเลขบอร์ดกับหน้าวันไม่ตรงกัน ทั้งที่ AGENTS.md ระบุว่าต้องตรงเสมอ

| # | อาการ | ต้นเหตุ | แก้ที่ |
|---|---|---|---|
| 1 | `needs_amount` ค้างบนรูปที่ไม่ใช่บิลแล้ว (3 รายการ) — **เคลียร์ไม่ได้ตลอดกาล** | `applyAiAnalysis` ล้างสถานะให้เฉพาะหมวด `bill` และ `bill_page` ตกเคส `other` | `db.js` + ฟังก์ชันซ่อม `clearNeedsAmountOnNonBills()` |
| 2 | `duplicate` ถูกนับเป็นงานค้าง (2 รายการ) | `listDays` กรองแค่ `status != 'unsent'` แต่หน้าจอกรอง `duplicate` ด้วย | `listDays` |
| 3 | คู่สำรองจ่าย–คืนเงิน นับเป็น 2 (หน้าวันแสดงเป็นชุดเดียว) | บอร์ดไม่รู้จักความสัมพันธ์ของ chain | `listDays` |
| 4 | `rejected` — หน้าวันนับ บอร์ดไม่นับ (4 รายการ) | SQL นับแค่ `unmatched` | `listDays` |
| 5 | `orphan_page` — หน้าวันนับ บอร์ดไม่นับ (1 รายการ) | SQL กรอง `bill_page` ทิ้ง | `listDays` |

> **ทำไมไม่มีใครสังเกต:** วันที่ 9 ส.ค. บั๊ก #2 (+1) กับ #5 (−1) **หักกลบกันพอดี**
> ตัวเลขรวมออกมา 4 = 4 ดูเหมือนถูก ทั้งที่องค์ประกอบข้างในผิดทั้งคู่

**ผลหลังแก้: ตรงกันครบ 67/67 รอบ**

### 4.2 บิลไม่มียอดนอนผิดถัง

บิลที่ AI อ่านยอดไม่ออกค้างเป็น `unmatched` → ไปโผล่ถัง "บิลไม่เข้าคู่" ซึ่งมีปุ่มเดียวคือ *เลือกสลิป*
แต่**จับคู่ไม่ได้ตลอดกาล** เพราะตัวจับคู่ให้คะแนนจากความใกล้ของยอด

`markBillsMissingAmount()` แก้ได้อยู่แล้ว แต่ถูกเรียกเฉพาะตอนกดปุ่ม "จัดคู่ใหม่"
→ ย้ายมาเรียก**ตอนบูตเซิร์ฟเวอร์**ด้วย (คู่กับ `markSemanticDuplicateBills`)

### 4.3 รูปที่ AI อ่านไม่สำเร็จ หายเงียบ

4 รูป (`#459`–`#462`) `ai_status='failed'` จาก OpenAI server error — ไม่มีป้ายบอก ไม่มีปุ่มลองใหม่
ปุ่ม "วิเคราะห์" ก็ไม่หยิบไปเพราะสถานะเป็น `failed` ไม่ใช่ `pending`

→ ขยาย `requeueAiItems()` ให้รับ `ai_status` + เมนู `ลองอ่านรูปที่ล้มเหลว` + ป้ายแดงบนหัว
**ทดสอบแล้ว: 4 รูปกลับเข้าคิว อ่านสำเร็จครบ failed เหลือ 0**

### 4.4 ตัวกรองกลุ่มบนหัวเว็บ

- กลับจากหน้าวัน/หน้าธง แล้วค่าใน dropdown ค้างเป็นกลุ่มของวันนั้น ไม่ตรงกับที่บอร์ดแสดง
- **เลือกกรองกลุ่มไม่ได้เลยตอนเพิ่งเปิดหน้าแรก** เพราะ dropdown สร้างจาก `S.items` ที่ยังว่าง

→ แยกเป็น `renderGroupOptions()` ที่ลิสต์ทุกกลุ่มเสมอ + คืนค่าตัวกรองของบอร์ดเมื่อกลับมา

### 4.5 ถังว่างกดไม่เข้า

กด "ต้องแก้ยอด 0" แล้วเด้งกลับถังที่มีงานเงียบ ๆ → เหมือนปุ่มเสีย และ empty state
`"ถังนี้ว่าง"` ไม่มีวันถูกเห็น

→ เพิ่ม `S.bucketPinned` เลือกถังอัตโนมัติเฉพาะตอนเข้าวันใหม่ ถ้าผู้ใช้กดเองให้อยู่ถังนั้น

### 4.6 หัวเรื่องเป็นเลข id เปล่า

บิลที่ AI อ่านชื่อร้านไม่ได้ แสดงหัวเรื่องว่า `คู่ #377`
→ เพิ่ม fallback: ชื่อร้าน → รายการ → **ประโยคแรกของสรุป AI** → `บิล #id`
